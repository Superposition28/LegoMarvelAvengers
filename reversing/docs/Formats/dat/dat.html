1. GAME*.HDR Structure (.CC40TAD v-8)

.CC40TAD v-8 .HDR Layout (All Multi-Byte Integers Big-Endian)
Offset Type Field Description
+0x00 u32be toc_sz TOC payload size in bytes (excluding initial u32be).
+0x04 char[8] magic ASCII ".CC40TAD" (reversed 4CC "DAT04CC.").
+0x0C i32be version Always -8 (0xFFFFFFF8).
+0x10 u32be hdr_flag Header flag (1 in inspected volumes).
+0x14 u32be fcnt Volume entry count (sum across 6 volumes = 81,232).
+0x18 u32be ncnt Prefix trie node count (10 bytes each).
+0x1C u32be str_len Byte length of packed ASCII string table starting immediately at +0x20.
+0x20 u8[str_len] str_buf String pool holding uppercase \-delimited names.
+0x20+str_len Node[ncnt] nodes 10-byte big-endian trie nodes >hHIH: (next_or_negfile, pad/flags, name_off, prev).
After nodes 0, -8, fcnt entry_hdr Three u32be/i32be framing fields before the entry array.
Entry array Entry[fcnt] entries 16-byte BE records: (u32be off_shifted, u32be csz, u32be usz, u32be meta) where codec = (meta >> 24) and sub_off = (meta & 0xFF); byte offset = (off_shifted << 8) | sub_off.
Hash array u32be[fcnt] hashes Direct TtPathHash table followed by collision header & dual "ROTV" blocks.

2. Codecs & ZIPX RC4 Encryption

Unlike earlier NXG releases that used unencrypted DFLT for all text/scripts, Avengers encrypts 5,980 plaintext/script assets (.sf, .txt, .txc, .sub, .xml, .cfg, .csv) with codec 6 (ZIPX): raw big-endian/RC4 payload encrypted using key = uint32_le(usz) (4-byte little-endian uncompressed size), then decompressed via bit-2-toggled raw Deflate (plain[0] ^= 0x04 if bit 2 is set, or standard raw Deflate — verified 100/100 sampled entries).

3. ROTV Dual MD5 Verification Tables

The TOC tail contains two "ROTV" sections (one storing u32be count + count * 16B compressed-stream MD5 digests, and the second storing count * 16B decompressed payload MD5 digests) allowing strict runtime integrity validation.

4. Standalone Clean-Room Parser Pseudocode

def parse_avengers_hdr(hdr_bytes):
    toc_sz, magic, ver = struct.unpack_from(">I8si", hdr_bytes, 0)
    assert magic == b".CC40TAD" and ver == -8
    hdr_flag, fcnt, ncnt, str_len = struct.unpack_from(">4I", hdr_bytes, 16)
    str_buf = hdr_bytes[32 : 32 + str_len]
    pos = 32 + str_len
    nodes = [struct.unpack_from(">hHIH", hdr_bytes, pos + i * 10) for i in range(ncnt)]
    pos += ncnt * 10
    assert struct.unpack_from(">IiI", hdr_bytes, pos) == (0, -8, fcnt)
    pos += 12
    entries = []
    for i in range(fcnt):
        off_s, csz, usz, meta = struct.unpack_from(">4I", hdr_bytes, pos + i * 16)
        codec = (meta >> 24) & 0xFF
        byte_off = (off_s << 8) | (meta & 0xFF)
        entries.append((byte_off, csz, usz, codec))
    # Decrypt codec 6 (ZIPX): rc4_decrypt(payload, key=struct.pack("<I", usz)), then zlib raw -15
    return nodes, str_buf, entries
